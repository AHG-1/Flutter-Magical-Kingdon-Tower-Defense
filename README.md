Uma recriação simples do jogo Sir we have an Orc Problem, feito em Flutter, onde você defende seu castelo de ordas de monstros magicos!!

🎮 Como funciona o jogo?
O jogo combina Tower Defense com ondas infinitas e progressão roguelike, onde cada partida oferece melhorias únicas para você sobreviver o máximo possível.

Controles: cliando na tela, voce pode colcar torres caso tenha recursos. E voce ganha recursos contratando Anoes para conseguir recursos.

🛠️ O que foi usado para criar
Flutter e Dart (ferramentas para criar aplicativos e jogos)
☠️Sempre use esse comando antes de executar o projeto
Run flutter pub get
